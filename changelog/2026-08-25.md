## Cart bar / checkout fix

- **Cart bar no longer blocks the cart drawer's checkout button (theme.css + theme.min.css; FINAL fix z-index 2147483646):** first attempt (9999999998, below the drawer's 9999999999) did nothing — browsers CLAMP all z-index values above 2^31-1 to 2147483647, so 9999999998/9999999999/10000000000 all computed to the SAME 2147483647 and paint order fell back to DOM order (bar renders after drawer → bar wins). Real fix: `.cart-bar` + `.cart-bar.is-visible` → 2147483646, genuinely one below the clamp ceiling; drawer (and dialogs) clamp to 2147483647 above it. Verified in-browser on the dev store: bar computes 2147483646 vs drawer 2147483647, drawer covers the bar, checkout button unobstructed (screenshot cartbar-test2.png; the button's disabled state = Broadcast's terms-acceptance gate, unrelated).
