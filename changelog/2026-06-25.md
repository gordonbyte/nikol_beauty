## custom-info-banner: grid layout for block-order mobile stacking
- Rewrote the layout from a fixed two-wrapper flex (media wrapper + content wrapper) to a flat CSS grid where every block is a direct grid child in block order. Desktop: 2 columns — media spans all content rows (`grid-row: 1 / span N`, N = content-block count) on the left/right per `media_position`; content blocks stack in the other column. This also replaces the absolute-fill height hack (media height = content height via the row span). Mobile: single column, everything stacks in block order — so the Media block's position among the blocks controls where the media appears on mobile.
- Block schema + both instances unchanged (no migration). Note: existing instances have Media first in block order, so mobile now shows media first (was content-first); reorder the Media block to change it. ⚠️ Grid/Swiper layout — needs dev-server preview.
- Later fixes: gaps between content blocks fixed (media absolutely fills its half instead of grid row-spanning, so content rows aren't stretched); wrapped the content in the theme's `.page-width` container so the banner aligns to the standard page width (not full-bleed), matching sibling sections.
