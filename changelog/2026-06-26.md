## Header background — single source of truth + transparent cleanup
Investigation finding: the header background option **already existed** — Broadcast core (`theme.css`) wires the `header_bg` theme setting (Theme settings → Colors → Header bar → Background) through `--COLOR-HEADER-BG` to the header. But the previous agency had overridden it with hardcoded colors in `assets/main.css`, so the setting did nothing. (Note: `main.css` line 1 is just an inline source map, not minified CSS — the real rules are readable.)
- **Removed all agency header-background overrides from main.css:** desktop hardcoded `white`; mobile hardcoded `#F7F2ED`; sticky + mega-menu `white !important`; homepage `.template-index` `#F7F2ED`; `#about`/`#videos` body-ID transparent hacks (incl. an `#about` menu hover color and `.theme__header::after` rules); `.template-blog`/`.related-articles` white; `.template-article` `#fcfaf8`.
- **Replaced with one clean, feature-driven system:** header bar background = `var(--COLOR-HEADER-BG)` (so `header_bg` is now the single source of truth); `.header__wrapper[data-header-transparent] .header__desktop/.header__mobile` → transparent (driven by the section's Transparent header toggles, matching core's presence-based `:has([data-header-transparent])`); sticky/mega-menu → solid `var(--COLOR-HEADER-BG) !important` (transparent at top, solid on scroll).
- **Added per-page transparent toggles** to the header section's "Transparent header" group: `transparent_about` and `transparent_videos` (both default **true** to preserve the current transparent look on those pages), wired in the `transparent_header` logic via `template.suffix == 'about' / 'videos'`. About/Videos transparency is now controlled from the editor instead of hardcoded CSS hacks.
- **Live impact (header is on every page — preview before deploy):** `header_bg` stays white (#ffffff), so headers that were beige/#fcfaf8 (homepage, mobile, article) become **white**. There's no single value preserving all old per-page variations — that's the trade-off of one source of truth (user chose white). About/Videos stay transparent via the new default-on toggles. Verified: header schema parses with both new toggles; no hardcoded header-bg overrides remain in active CSS; new var-based rules present (main.css lines 241/244–245/252).
