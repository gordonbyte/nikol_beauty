## Dead-code cleanup #6: gift-card section reference fixed (real customer-facing bug)
- `templates/gift_card.liquid` line 40 called `{%- section 'gift-card.liquid' -%}` — the `{% section %}` tag takes the name **without** extension, so Shopify looked for `gift-card.liquid.liquid` and issued-gift-card pages rendered a visible Liquid error instead of the branded header (store logo + shop URL from `sections/gift-card.liquid`). Fixed to `{%- section 'gift-card' -%}`; synced to shopify-dev.
- Rest of the page (card value, code, QR, Apple Wallet) was unaffected — the template renders those itself.
