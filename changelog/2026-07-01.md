# Changelog — 2026-07-01

Product titles set to font-weight 600 across the theme. Changes local/uncommitted; git commits handled separately.

## Product titles → font-weight 600
Three weight sources controlled the two title contexts; updated each so all product titles render at 600.

- **Product card titles** (`.product-item__title`): `assets/theme.css` — base rule changed `font-weight: var(--FONT-WEIGHT-BODY)` (400) → `600`. No more-specific card rule redeclares weight, so this single base rule covers every card instance. (Inter body font; 600 weight already loaded.)
- **PDP title, standard product page** (`.template-product .product__title`): `assets/main.css` — added `font-weight: 600`. Previously inherited `h1 { font-weight: var(--FONT-WEIGHT-HEADING) }`. (Cormorant heading font; 600 weight already loaded.)
- **PDP title, coming-soon template** (`.product__title__wrapper h1.product__title.heading-size-6 span`): `snippets/cw-pdp-css.liquid` — changed the `!important` weight `500` → `600` (this rule wins on that template; only rendered by `custom-product-coming-soon.liquid`).

### Pages affected
Card titles (`.product-item__title`):
- Collection pages
- Homepage / landing sections with product grids (featured collections, product grids, "brick"/video-product-hub blocks)
- Search results page
- Related products / recommendations (bottom of product pages)

PDP title (`.product__title`):
- All standard product pages (`.template-product`): default product template + `product.free-products`, `product.new`, `product.waitlist` variants
