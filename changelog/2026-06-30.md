# Changelog — 2026-06-30

Typography cleanup on `shopify-live`: removed all hard-coded Jost font references so affected elements inherit the global body font (Inter via `--FONT-STACK-BODY`). Changes local/uncommitted; git commits handled separately.

## Removed all hard-coded `Jost` (56 references)
Context: earlier we set body font = Inter and removed Jost from the Google Fonts `<link>`. That left ~41 elements still hard-coding `font-family: 'Jost'`, which then fell back to a system font (most visibly the main nav + many titles). Stripped every active reference so they inherit `<body>` (= `var(--FONT-STACK-BODY)` = Inter) instead of overriding it.

- `assets/main.css` — 32 references: 30 standalone `font-family: 'Jost'` declarations deleted (inherit); 2 `font:` shorthand nav rules (`.navlink--toplevel .navtext`, `.navlink--child .navtext`) converted to longhand `font-size`/`line-height` (kept size, dropped family); removed the now-empty `.ff-jost {}` utility rule.
- `assets/theme.css` — 1: `.highlights { font-family: jost }` deleted.
- `sections/video-gallery.liquid` & `sections/video-gallery-youtube.liquid` — 3 each: hero/featured-product/bottom-hero description+title font-family removed.
- `sections/custom-product-coming-soon.liquid` — 1: removed inline `style="font-family:'Jost'"` on the "Included products" heading.
- `templates/metaobject/beauty_tutorial_videos.liquid` — 1: `.hero-subtitle` font-family removed.
- `templates/product.json`, `product.free-products.json`, `product.new.json`, `product.waitlist.json` — 5 each: removed inline `style="font-family:'Jost'"` on "Included products" `<b>` labels inside the custom_liquid block.
