## DEV — Mini review slider: curated-only, random order (2026-09-23)

- Per Randell: stop putting photo reviews first, make the order random; and "if it is not curated then do not show anything". Two changes in `sections/custom-product-coming-soon.liquid`, pushed to the dev theme.
- **Ordering.** `arrange()` used to split the curated set into "has photo" and "no photo", shuffle each group, then concatenate photo-group first — so a photo review always led. It now shuffles the whole list, so every curated review has an equal chance of showing first.
- **Curated-only.** `pick()` used to fall back to an automatic selection (4–5★ titled reviews, ranked photo-first then by rating and recency) whenever no tagged review was found. That fallback is gone: `pick()` now returns only reviews carrying the curated tag. An empty result sets `data-junip-empty`, which the existing CSS already hides, so the block disappears rather than showing untagged reviews.
- **This also closes the fallback-quote problem flagged on 2026-09-22.** The hard-coded BB Crème testimonial in the block ("my aunty, who is 86 years young") can no longer surface on another product's page, because a product without matching curated reviews now renders nothing at all.
- Verified on the dev store with fresh browser contexts each run, so no session cache:
  - **Randomness** — Rose Lip Balm over 6 loads: 4 different reviews led, and its single photo review led once in six. Its curated set is 4 reviews of which 1 has a photo, so ~1 in 4 is exactly the expected share. Before the change that review led every single time.
  - **Untagged hides** — BB Crème (no `review_tag`) now renders nothing, twice out of two.
  - **Tag with no matching reviews hides** — 10x Magnification Mirror, whose tag is set but returns nothing against the dev product id, also renders nothing instead of the fallback quote. That is the correct outcome for the dev-store mapping gap noted yesterday.
  - **Tagged still render** — Eye Primer, The Cabana, Champs and Gua Sha all serve curated reviews normally.
