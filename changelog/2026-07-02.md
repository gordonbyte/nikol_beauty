## Promo % badge system (tag-driven) — NEW
A promotional-pricing display driven entirely by **product tags**. Purely visual: the actual discount is a Shopify automatic/cart discount applied at checkout, so tagged products must be kept in sync with the discount's product list or cards will advertise a price the cart won't honor.

- **`config/settings_schema.json`** — new "Promo % badge" settings group under Colors: `promo_badge_enable` (checkbox, default on), `promo_badge_bg_color` (default `#14448A`), `promo_badge_text_color` (default `#ffffff`). Info text explains the `promo-20` tag convention.
- **`snippets/product-grid-item.liquid`** — reads the `promo-<n>` or `promo-up-to-<n>` tag off each product. Renders:
  - a circular "% OFF" bubble positioned **top-left** of the product image (top-right is left for the theme's existing sale/badge bubble, so they never collide). `promo-up-to-<n>` renders a two-line "Up to / N% OFF".
  - a calculated price block in the card price area: struck-through original + computed sale price + an "On Sale" pill. Sale price = `price_min − (price_min × percent / 100)`.
  - only shown when the product is available and the badge setting is on.
- **`snippets/product-price.liquid`** — the same promo price treatment on the PDP, but **single-variant products only** (multi-variant prices change with variant selection, which is handled by theme JS, so those keep the normal price line). Reads `promo-<n>` / `promo-up-to-<n>`.
- **`assets/styles.css`** — +121 lines of layout CSS: `.promo-box` (circular badge + mobile size-down at ≤768px), `.price--promo` / `.product__price--promo` flex layouts, `.promo-old-price` slanted `#fcc9c6` strikethrough, `.promo-new-price`, and the `.promo-on-sale-pill`. Colors come inline from the theme settings; the CSS only handles layout. On the PDP the theme's default price node is hidden (kept in the DOM so JS hooks stay intact).
