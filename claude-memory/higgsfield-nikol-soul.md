On 2026-10-05 Randell asked "are you aware of the nikol soul in higgsfield". It exists:
- **Soul:** `soul_id` 27940312-ad48-4d06-af9f-dabdcfd4c3d7, name "Nikol", type soul_2. It works only with `model: "soul_2"` (or soul_cinematic). It gives realistic candid phone-photo or UGC looks with a consistent Nikol face.
- **Reference element:** "Nikol", id 4125bdbb-8f35-4000-bc42-68273bd95315 (19 photos, not 1). Use it in Nano Banana Pro or GPT Image prompts as `<<<4125bdbb-8f35-4000-bc42-68273bd95315>>>`.
- **Gotcha:** soul_2 accepts only ONE image, and it uses that image as the whole composition. Passing a product photo returned three bullet close-ups and no Nikol. Run the Soul text-only, then swap in the exact product with a nano_banana_pro edit (the Soul result plus the product image, with "replace only the product" in the prompt).
